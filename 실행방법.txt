========================================
  AI Cover Letter Assistant 실행 방법
========================================

[필수 준비]
1. Node.js 설치
2. Python 3.x 설치
3. MySQL 실행 (DB)
4. 루트 폴더에 .env 파일 설정
   - OPENAI_API_KEY, NAVER_CLIENT_ID, NAVER_CLIENT_SECRET
   - GOOGLE_APPLICATION_CREDENTIALS (GCP Vision JSON 경로)
   - DB_HOST, DB_USER, DB_PASSWORD, DB_NAME 등

----------------------------------------
1. 의존성 설치
----------------------------------------
# 루트에서 (Node)
npm install

# Python 분석 서버 (aiServer 폴더에서)
cd aiServer
pip install -r requirements.txt
cd ..

----------------------------------------
2. DB 마이그레이션 (최초 1회)
----------------------------------------
npm run migrate

----------------------------------------
3. 서버 실행 (3개 모두 실행)
----------------------------------------
※ 터미널을 3개 띄워서 각각 실행하세요.

[터미널 1] Node 백엔드 (Express, 포트 3000)
  npm run server

[터미널 2] 프론트엔드 (Vite)
  npm run app

[터미널 3] Python 분석 API (FastAPI, 포트 8000)
  cd aiServer
  python -m uvicorn main:app --reload --port 8000

----------------------------------------
4. 접속
----------------------------------------
- 프론트: http://localhost:5173 (Vite 기본 포트)
- Node API: http://localhost:3000
- 분석 API: http://localhost:8000
